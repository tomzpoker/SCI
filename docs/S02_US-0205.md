# S02 — US-0205 — Réutiliser les moteurs communs

**Statut : IMPLEMENTED — REVIEW WINDOWS/POSTGRES REQUIRED**

US-0205 pose le contrat partagé d'exécution par entité sans dupliquer les moteurs métiers pour SCI/SARL.

Moteurs couverts : Calcul, Événements, Workflow, Banque, TVA, Documents, Trésorerie, Audit.

Le contexte commun est chargé à partir de `legal_entities` puis réutilisé par les fonctions serveur déjà présentes. Les helpers TVA et trésorerie sont purs et testables sans PostgreSQL.
