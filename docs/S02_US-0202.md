# S02 — US-0202 — Gérer les activités d’une SARL

**Statut :** **IMPLEMENTED — REVIEW WINDOWS/POSTGRES REQUIRED**

## Objectif
Permettre à une même SARL d’activer plusieurs activités dans le même périmètre juridique, notamment les activités documentées `MARCHAND_DE_BIENS` et `GARAGE_AUTO`, sans créer de seconde société artificielle.

## Design
- catalogue métier versionné dans `legal_activity_catalog` ;
- association N:N dans `legal_entity_activities` ;
- plusieurs activités actives simultanément ;
- une seule activité principale active au maximum ;
- garde côté service Rust et contrainte côté PostgreSQL : seules les entités `SARL` sont admissibles ;
- audit de chaque activation, désactivation et changement d’activité principale ;
- aucune modification des flux métiers historiques : leur cloisonnement relève de US-0203.
