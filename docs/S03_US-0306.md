# US-0306 — Rendre les calculs reproductibles

## Objectif
Pouvoir expliquer un résultat critique à partir des données réellement utilisées au moment du calcul.

## Couverture
`rule_calculation_runs` conserve les entrées, la RuleVersion, le snapshot de la règle, la source, une formule lisible, le résultat et le mode d'arrondi. `explain_calculation_run` restitue ces éléments dans le contexte de l'entité active.

## Principe
Aucune formule métier n'est reconstruite à partir de la règle actuelle : l'explication se rattache au run et au snapshot de la version historique.
