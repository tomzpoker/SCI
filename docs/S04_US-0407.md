# S04 — US-0407 — Rendre les jobs idempotents

Une opération relancée avec la même clé et les mêmes entrées réutilise son résultat au lieu de créer un doublon.

## Couverture
- `job_executions` : clé d’idempotence, hash d’entrée, état, tentative et résultat.
- Factures : `invoices.idempotency_key`.
- Encaissements : `payments.idempotency_key`.
- Anticipation : cycle quotidien protégé par clé d’idempotence.
- Les tâches gardent leur unicité `legal_entity_id + code + occurrence_key`.
- Les flux bancaires conservent leur unicité par `legal_entity_id + external_id`.

## Sécurité
Une même clé réutilisée avec une autre charge utile est refusée. Aucun traitement destructif n’est introduit.
