# US-0807 — Gérer les niveaux de rapprochement

## Objectif
MATCHED, PROBABLE, TO_VALIDATE, UNMATCHED et ANOMALY sont stockés et traduits dans l’UI en français. Les changements sont journalisés.

## Implémentation
Migration `0018_banking_reconciliation.sql` et module `src/banking.rs`, avec intégration UI dans `src/ui.rs`.

## Contrôle
Le script `scripts/verify-s08-banking.ps1` vérifie la présence du schéma, des fonctions métier et l’absence d’opérations SQL destructives introduites par S08.
