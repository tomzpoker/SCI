# US-0707 bis — Accueillir la facturation électronique

Le modèle mémorise une plateforme active, conserve les anciennes plateformes et journalise les événements. Le cœur métier utilise une frontière d'adaptation neutre afin de permettre un changement ultérieur de plateforme sans réécrire les factures historiques.

Le S07 ne réalise pas encore l'envoi réel vers une plateforme agréée ; il prépare et journalise le flux.
