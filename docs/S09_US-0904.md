# US-0904 — Transformer une prévision en événement

## Objectif
La matérialisation crée un événement prévisionnel avec états SCHEDULED, PENDING, AWAITING_BANK_MATCH, MATCHED, COMPLETED ou CANCELLED, traduits dans l’UI.

## Implémentation
Migration `0019_treasury_forecast.sql` et module `src/treasury.rs`.

## Contrôle
Le script `scripts/verify-s09-treasury.ps1` vérifie les classifications, horizons, états, catégories d’investissement et l’absence de SQL destructif introduit par S09.
