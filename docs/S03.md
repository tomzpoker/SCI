# S03 — Référentiels + Rule Engine

Sprint livré côté source : US-0301 à US-0305.

## US-0301 — Référentiels versionnés
`versioned_references` impose version, période de validité, source, vérification et statut. Les références publiées sont immuables.

## US-0302 — Rulesets par périmètre
`rule_definitions` + `rule_versions` supportent entité, activité SARL, juridiction et période. La résolution sélectionne la version publiée la plus spécifique compatible avec la date demandée.

## US-0303 — Rejouer un calcul historique
`rule_calculation_runs` conserve RuleVersion, date, entrées et résultat. Le Rule Engine réévalue une définition déterministe et compare le résultat original au replay.

## US-0304 — Sources fiscales officielles
Les RuleVersions publiées exigent une source référencée. Les sources maîtres initiales sont enregistrées dans la migration sans inventer de taux ou de règle fiscale.

## US-0305 — Gérer une évolution de loi
Une RuleVersion publiée est append-only et ne peut pas être modifiée. L'évolution se fait par nouvelle version et par nouvelles périodes de validité ; les versions publiées qui se chevauchent sur un même périmètre sont refusées.

## Validation
Le script `scripts/verify-reference-rule-engine.ps1` vérifie les marqueurs structurants et l'absence d'opérations SQL destructives. La compilation Windows et l'exécution PostgreSQL restent à certifier sur le PC cible.

## US-0306 — Rendre les calculs reproductibles
Chaque run conserve entrées + règle/version + source + formule + résultat + arrondi et une API `explain_calculation_run` restitue le dossier explicatif.
