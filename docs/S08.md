# SPRINT 8 — BANQUE & RAPPROCHEMENT

Statut : **COMPLETE / REVIEW**.

Le sprint ajoute un vertical slice bancaire sans supprimer le modèle historique. Les imports CSV, OFX et PDF/OCR convergent vers le même pipeline, conservent la source et calculent un hash stable. Le rapprochement reste explicite et traçable.

## US couvertes
- US-0801 — Gérer les comptes bancaires.
- US-0802 — Importer CSV.
- US-0803 — Importer OFX.
- US-0804 — Importer les relevés PDF/OCR.
- US-0805 — Détecter les transactions.
- US-0806 — Rapprocher automatiquement.
- US-0807 — Gérer les niveaux de rapprochement.
- US-0808 — Séparer les soldes.

## Limites assumées
Le parseur PDF dépend d’un moteur OCR local configuré par `SCI_OCR_COMMAND`. L’UI MVP accepte le CSV/OFX sous forme de texte et le PDF via chemin local ; les server functions sont séparées pour permettre ensuite un sélecteur de fichiers natif.
