# US-0806 — Rapprocher automatiquement

## Objectif
Règles explicites pour loyers/factures, paiements partiels, paiements multiples, frais, virements internes, dépôts, remboursements, impayés et flux inconnus. L’automatisme privilégie la validation humaine lorsque la confiance n’est pas suffisante.

## Implémentation
Migration `0018_banking_reconciliation.sql` et module `src/banking.rs`, avec intégration UI dans `src/ui.rs`.

## Contrôle
Le script `scripts/verify-s08-banking.ps1` vérifie la présence du schéma, des fonctions métier et l’absence d’opérations SQL destructives introduites par S08.
