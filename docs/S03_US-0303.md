# US-0303 — Rejouer un calcul historique

## Livré
Chaque run de calcul conserve la RuleVersion exacte, la date d'effet, les entrées et la sortie. Le replay recharge la définition historique, recalcule et signale si le résultat est identique.

Le DSL volontairement minimal supporte `PASS_THROUGH`, `ADD`, `SUBTRACT` et `MULTIPLY_BPS`.
